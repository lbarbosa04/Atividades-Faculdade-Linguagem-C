<h1 align="center">Atividades de Programação em C — 1º Semestre</h1>

## Sobre este repositório

Este repositório reúne os exercícios e programas desenvolvidos durante o **primeiro semestre da faculdade**, utilizando a linguagem **C** e **Arduino**.

O objetivo é praticar os conceitos fundamentais da lógica de programação e da sintaxe da linguagem C, servindo tanto como material de estudo quanto como registro da evolução do aprendizado ao longo do semestre.

## Tecnologias utilizadas

- **Linguagem:** C
- **Compilador:** C Online Compiler
- **Tinkercad** Utilizado para teste e codigo

## Conteúdos abordados

Os exercícios deste repositório exploram tópicos como:

- Entrada e saída de dados (`scanf`, `printf`)
- Estruturas condicionais (`if`, `else`)
- Estruturas de repetição (`for`, `while`, `do-while`)
- Manipulação de variáveis e operadores aritméticos/lógicos
- Vetores (arrays)
- Arduino

## Observações

Este é um repositório de **estudos**, então o código pode não seguir todas as boas práticas de um projeto profissional — o foco aqui é o aprendizado e a fixação dos conceitos básicos da linguagem C.
