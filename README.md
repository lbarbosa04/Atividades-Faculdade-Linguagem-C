# Atividades de Programação em C — 1º Semestre

## Sobre este repositório

Este repositório reúne os exercícios e programas desenvolvidos durante o **primeiro semestre da faculdade**, utilizando a linguagem **C**.

O objetivo é praticar os conceitos fundamentais da lógica de programação e da sintaxe da linguagem C, servindo tanto como material de estudo quanto como registro da evolução do aprendizado ao longo do semestre.

## Tecnologias utilizadas

- **Linguagem:** C
- **Compilador:** C Online Compiler

## Conteúdos abordados

Os exercícios deste repositório exploram tópicos como:

- Entrada e saída de dados (`scanf`, `printf`)
- Estruturas condicionais (`if`, `else`)
- Estruturas de repetição (`for`, `while`, `do-while`)
- Manipulação de variáveis e operadores aritméticos/lógicos
- Vetores (arrays)
